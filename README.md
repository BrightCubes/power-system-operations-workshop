# power-system-operations-workshop

A workshop on power system operations using Power Grid Model.

This workshop was loosely based on https://github.com/PowerGridModel/power-grid-model-workshop.

## Setup

1. Open a terminal.
2. Download or clone this repository, e.g. using `git clone git@github.com:PowerGridModel/power-grid-model-workshop.git`.
3. Install `uv` using the steps in https://docs.astral.sh/uv/getting-started/installation/.
4. Install the dependencies using `uv sync`

## Follow the assignment

1. Open [power-system-operations-workshop-assignment.ipynb](./power-system-operations-workshop-assignment.ipynb) in a notebook editor of your choice.
2. Follow the workshop.
3. You can find the answers in [power-system-operations-workshop-answers.ipynb](./power-system-operations-workshop-answers.ipynb) (or you can use it as a cheat-sheet).
4. Good luck.
